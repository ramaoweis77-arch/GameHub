# GameHub

## Project Description
GameHub is a React-based web application designed to
provide an interactive gaming-related experience.

## Setup Instructions

1. Install Node.js.
2. Clone the repository:

   ```bash
   git clone https://github.com/ramaoweis77/Web2Project.git
   ```

3. Open the project folder:

   ```bash
   cd Web2Project
   ```

4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the application:

   ```bash
   npm start
   ```

6. Open http://localhost:3000 in your browser.
